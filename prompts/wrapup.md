# 作業終了用プロンプト（ChatGPT など）

作業の最後に、このチャット（ChatGPT のプロジェクト内）へ貼る。
出力された内容を、GitHub の Issue フォーム（`New issue` → 「作業終了の記録」）の「要約」欄にそのまま貼って送信すると、
logs/・STATUS.md・INDEX.md に自動で反映される（数十秒）。結果は Issue のコメントに出る。

※ ChatGPT のプロジェクト指示に「終了」と言われたらこの形式で出す、と入れておけば、このプロンプトを貼る必要はない（`prompts/chatgpt-project-instructions.md` 参照）。

---

ここまでの作業を、次の形式で簡潔にまとめてください。会話の全文は不要です。
コードブロックに入れて出力してください。
APIキー・パスワード・個人情報は含めないでください（必要なら匿名化）。
見出しと項目名は、下の例とまったく同じ表記にしてください。

```
使ったAI: ChatGPT
概要: （この案件の現状を1行で）
状態: active

## やったこと
- ...

## 決めたこと
- 決定内容 | 理由
（なければこの見出しごと省略）

## 次回へ
- （次に着手する順に。最初の1行がINDEXに出ます）

## 現状
（いまどこまで進んでいるか、3〜5行）
```

状態は active / waiting（相手待ち）/ paused（保留）/ done（完了）のどれか1つ。
